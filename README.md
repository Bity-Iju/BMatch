# BMatch 💙

**BMatch** is a professional and secure matchmaking application built with Expo and React Native, specifically designed to foster a safe and supportive community for HIV-positive individuals in Nigeria.

![Version](https://img.shields.io/badge/version-1.0.9.26-navyblue)
![Platform](https://img.shields.io/badge/platform-Android%20%7C%20iOS-blue)
![Tech](https://img.shields.io/badge/tech-Expo%20SDK%2051-skyblue)

---

## 🌟 Key Features

- **Professional Onboarding**: A comprehensive 6-step registration process ensuring community integrity.
- **Smart Location Selection**: Dynamic dropdowns containing all **36 Nigerian States** and **774 Local Government Areas (LGAs)**.
- **Modern UI/UX**: Professional "Bootstrapped" design using a modern blue color palette (`Navy Blue`, `Dark Blue`, `Ocean Blue`).
- **Secure Consent**: Integrated disclaimer and safety acknowledgement to maintain a secure environment.
- **Responsive Components**: Custom-built reusable buttons and inputs optimized for performance.
- **Native Animation**: High-performance transitions powered by `react-native-reanimated` and NativeWind v4.

---

## 🚀 Tech Stack

- **Framework**: [Expo SDK 51](https://expo.dev/) (Managed Workflow)
- **Styling**: [NativeWind v4](https://www.nativewind.dev/) (Tailwind CSS for React Native)
- **Navigation**: [Expo Router v3.5](https://docs.expo.dev/router/introduction/) (File-based routing)
- **Language**: TypeScript
- **Package Manager**: pnpm

## 📦 Installation & Setup

Ensure you have [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) installed.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/BMatch-Expo.git
   cd BMatch-Expo
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   ```

3. **Start the development server**:
   ```bash
   # Use the clean flag to ensure the professional theme & routes are fresh
   npx expo start -c
   ```

4. **Run on Android/iOS**:
   Press `a` for Android Emulator or `i` for iOS Simulator in the terminal.

## 🎨 Design Guidelines

The app follows a professional blue brand identity:
- **Navy Blue (`#000080`)**: Primary actions and branding.
- **Dusty Blue (`#4D7C9E`)**: Secondary elements and icons.
- **Ocean Blue (`#0077BE`)**: Links and highlights.
- **Surface (`#F8FAFC`)**: Modern background tint.

## 🛡️ Safety & Privacy

BMatch prioritizes user safety. Registration requires verification of:
- Healthcare Facility Name
- ART ID / Hospital Number
- Explicit HIV Status Acknowledgment
